## Projects

### 🎩 [Chapeau](https://chapeau.hypnodron.com)

**One phone. Three rounds. Everyone plays.**

Pass one phone around for three rounds of descriptions, charades, and single-word clues. Each round reuses the same words, and you can play offline.

### 💡 [AirPickup](https://airpickup.hypnodron.com)

**Your screen is the cable.**

Send files from one device's screen to another's camera through animated QR codes. Works without an internet connection or shared network.

### 📰 [CrossFeed](https://crossfeed.hypnodron.com)

**Many sources. One daily read.**

Follow Hacker News, Lobsters, Slashdot, and other tech news sources through one consistent reader. Each source fits the same layout, so you can browse the news in one place.

### 🎲 [Gambler's Dice](https://gamblers-dice.hypnodron.com)

**These dice have a memory.**

A dice toy where previous throws influence the odds of the next roll. It puts the gambler's fallacy into practice, as if a number could become "due."

### 🌍 [IP State](https://github.com/hypnodron/IPState)

**Know your IP without the browser.**

A native macOS menu bar app for your public IP, approximate location, and connection status. Optional alerts help you catch IP changes and connection problems.
